# Основы информационной безопасности
# Описание
Реализована гибридная криптосистема с использованием асимметричного алгоритма **RSA** и симметричного **AES**. 
Создано веб приложения на flask с модулем Crypto
# Запуск
Чтобы все работало необходимо установить `requirements.txt`

## Лабораторная №3 "Построение гибридной криптосистемы"
`python app.py` и перейти на `http://127.0.0.1:5000/` - веб приложение

Результат данной лабораторной работы - гибридная криптосистема - будет сочетать в себе преимущества симметричных и асимметричных алгоритмов шифрования и в целом даже напоминать системы, использующиеся на практике.

Пользовательские настройки в `/config/config.py` и настройки шифрования в `/config/crypto_config.py`
# Файлы проекта
`app.py` - веб-приложение

Работать она будет следующим образом: сообщение шифруется при помощи симметричного алгоритма, а ключ симметричного алгоритма - ассиметричным. В качестве асимметричного алгоритма будет использоваться RSA, симметричный алгорим выбирается в соответствии с вариантом.


`/crypto` - код для RSA, AES, сериализации и гибридной криптосистемы

`/config` - файлы конфигурации

`/key` - путь с файлами сгенерированных ключей

`/uploads` - путь с файлами шифрованных/расшифрованных файлов

`/static` и `/templates` - фронт для сайта
