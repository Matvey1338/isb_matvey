# Лабораторная №2 "Статистический анализ псевдослучайных последовательностей"

## Отчет
В рамках данной лабораторной работы я разработал консольное и веб-приложение на Flask для генерации и анализа случайных последовательностей. Для генерации последовательностей я использовал программы на языках Java и C++.

запустить java генератор через java .\RandomGenerator128_java.java 


Я реализовал три NIST теста для анализа случайности последовательностей:
1. Частотный побитовый тест (`frequency_bit_test.py`)
2. Тест на одинаковые подряд идущие биты (`runs_test.py`)
3. Тест на самую длинную последовательность единиц в блоке (`block_frequency_test.py`)
